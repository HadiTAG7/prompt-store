## Design system extracted from references (source of truth)

**Font**: Rubik (Latin+Arabic). Self-host via `@fontsource-variable/rubik` (design loads from Google Fonts; self-hosting keeps the app offline-capable).

**Core tokens** (light mode; full dark mode exists in the reference `fig-tokens.css` under `[data-theme="dark"]` and will be carried over verbatim):
- Primary `rgb(54,70,232)`, primary-container `rgb(209,221,255)`, on-primary-container `rgb(10,0,92)`
- Secondary `rgb(0,99,183)` (also hover color for primary buttons & links, and the 3px inset focus ring on inputs)
- Success `rgb(31,116,87)` / container `rgb(168,240,209)`; Danger `rgb(178,36,50)` / container `rgb(255,209,206)`; Gold/warning `rgb(182,156,82)` / container `rgb(246,220,151)`
- Surface (page bg) `rgb(245,249,254)`; card bg = white (`surface-container-lowest`); surface-container `rgb(229,236,245)`; on-surface `rgb(23,27,32)`; on-surface-medium `rgb(67,72,78)`; on-surface-low `rgb(109,114,121)`; outline `rgb(185,190,198)`; outline-variant (hairlines) `rgb(215,223,233)`; inverse-surface `rgb(42,46,52)` (toasts)
- Radii: xs 4 / sm 8 / md 12 / lg 16 / pill 9999 (dialogs 20)
- Shadows: sm `0 1px 2px rgba(0,0,0,.08)`, md `0 4px 16px rgba(0,0,0,.12)`, lg `0 8px 32px rgba(0,0,0,.16)`; dialog scrim `rgba(0,0,0,.4)`
- Spacing: 8px grid (4/8/12/16/24/32/40/48/64)
- Motion: 120ms ease background transitions, 160ms toast entry, 200ms progress width; hover = same-color state layer ~8%, press ~16%, disabled opacity .38
- Numerals: Eastern-Arabic digits everywhere (`٣٠٪`, `١٠ خطوات`) — a `formatArabicNumber` util

**App shell** (Dashboard/Workflows/Details/Editor/Library pages):
- Sidebar: 264px, white, `border-inline-end` hairline, padding 20px 16px; logo = 32px tile radius 8 primary bg + `ph-stack` fill icon + app name 17px/700; full-width primary button "إنشاء مسار جديد"; nav items h-40 radius-12 gap-12 icon-20 text-15 (active: primary-container bg + on-primary-container fg + weight 600 + filled icon; hover: surface-container-low); badge pill (workflow count); bottom user card (static, per design: avatar "س", "سارة العتيبي" / "فريق الاستشارات") on `surface` bg radius 12
- Header: 64px, white, hairline bottom, padding 0 32px, sticky; SearchField 400×40 (placeholder "ابحث في المسارات والبرومبتات"); left cluster (RTL end): 40px round quick-create btn (primary-container), 40px round theme toggle (moon/sun), 1×24 divider, avatar+caret menu
- Content: padding 32px, max-width 1240px centered (Details page: 1080px, padding 28px 32px 48px)

**Buttons** (from specimen page + usages): medium h-40 radius-12 padding ~0 16-20px text 14-15/500; small h-32/radius-8; large h-48. Variants: primary filled (bg primary, white text, hover → secondary); neutral-outline ("محايد"/"حفظ": white bg, outline-variant border, on-surface text, hover surface-container-low); tonal (primary-container bg); text/ghost; danger filled. Disabled 38% opacity. Icon buttons 32–40px round, transparent, hover surface-container (danger hover: danger-container + danger fg).
